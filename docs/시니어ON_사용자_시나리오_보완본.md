# 시니어ON 사용자 시나리오

- 팀명: SeniorOn
- 팀장: 연두 / 신연주
- Android 팀장: 원스톤 / 신한석

## 용어

- **자녀(보호자) 모드**: 시니어의 기기와 건강·안전 정보를 관리하는 가족 사용자가 이용하는 모드
- **시니어 모드**: 시니어가 큰 글씨와 간편한 버튼으로 사용하는 런처형 모드
- **주 담당자**: 가족을 생성하고 시니어 정보를 최초로 등록하는 보호자
- **보조 담당자**: 가족 공유 코드로 참여하여 시니어와의 관계를 등록하는 보호자

# 1. 공통 사용자 시나리오

## 1.1 앱 실행 및 모드 선택

1. 사용자가 시니어ON 앱을 실행한다.
2. 스플래시 화면에서 저장된 로그인 세션의 유효성을 확인한다.
3. 유효한 세션이 있으면 계정 역할과 온보딩 상태를 확인해 이어서 진행할 화면으로 이동한다.
4. 유효한 세션이 없으면 사용자 모드 선택 화면을 표시한다.
5. 사용자는 자녀(보호자) 모드 또는 시니어 모드를 선택하고 확인한다.
6. 선택한 모드에 맞는 로그인 화면으로 이동한다.

**예외 및 안내**

- 저장된 세션이 만료되었고 갱신할 수 없으면 다시 로그인할 수 있도록 안내한다.
- 네트워크 문제로 온보딩 상태를 확인하지 못하면 임의의 화면으로 이동하지 않고 재시도할 수 있도록 안내한다.

## 1.2 회원가입

1. 사용자가 로그인 화면에서 회원가입을 선택한다.
2. 카카오, 구글 또는 이메일 중 가입 방법을 선택한다.
3. 선택한 사용자 모드가 자녀 모드인지 시니어 모드인지 확인한다.
4. 이름과 생년월일을 입력한다.
5. 이메일 가입 사용자는 이메일 인증을 진행한다.
6. 이메일 가입 사용자는 아이디를 입력하고 중복 여부를 확인한다.
7. 비밀번호와 비밀번호 확인 값을 입력한다.
8. 소셜 가입 사용자는 이메일 인증과 아이디·비밀번호 입력을 건너뛴다.
9. 필수 이용약관에 동의하고 회원가입을 완료한다.
10. 회원가입 완료 후 로그인 화면으로 이동한다.

**예외 및 안내**

- 이미 사용 중인 아이디 또는 이메일이면 중복 안내를 표시하고 다른 값을 입력하도록 한다.
- 이메일 인증번호가 올바르지 않거나 만료되면 다시 입력하거나 재전송할 수 있도록 안내한다.
- 필수 약관에 동의하지 않으면 회원가입을 완료할 수 없다.

## 1.3 로그인

1. 사용자가 아이디와 비밀번호를 입력한다.
2. 자녀 모드에서는 필요할 경우 로그인 상태 유지를 선택한다.
3. 로그인 버튼을 누른다.
4. 시스템이 로그인 계정의 역할과 사용자가 선택한 모드가 일치하는지 확인한다.
5. 로그인 성공 후 가족 연결 여부, 시니어 정보 및 온보딩 완료 상태를 확인한다.
6. 온보딩이 완료된 자녀 사용자는 자녀 메인 화면으로 이동한다.
7. 온보딩이 완료된 시니어 사용자는 시니어 홈 화면으로 이동한다.
8. 카카오 또는 구글 계정으로도 로그인할 수 있다.
9. 시니어 모드는 런처 동작을 유지하기 위해 로그인 유지 선택 여부와 관계없이 세션을 보관한다.

**예외 및 안내**

- 아이디 또는 비밀번호가 올바르지 않으면 로그인 정보 확인 안내를 표시한다.
- 계정 역할과 선택한 모드가 다르면 올바른 모드로 로그인하도록 안내한다.
- 네트워크 연결에 실패하면 입력 오류와 구분된 네트워크 오류 안내를 표시한다.

## 1.4 아이디 찾기

1. 사용자가 로그인 화면에서 아이디 찾기를 선택한다.
2. 계정에 등록한 이름과 이메일을 입력한다.
3. 시스템이 일치하는 계정을 조회한다.
4. 계정이 확인되면 아이디와 가입일을 표시한다.
5. 사용자는 로그인 또는 비밀번호 찾기로 이동할 수 있다.

**예외 및 안내**

- 일치하는 계정이 없으면 입력한 이름과 이메일을 다시 확인하도록 안내한다.

## 1.5 비밀번호 찾기

1. 사용자가 로그인 화면에서 비밀번호 찾기를 선택한다.
2. 이름과 아이디를 입력한다.
3. 등록된 이메일로 인증번호 전송을 요청한다.
4. 수신한 인증번호를 입력한다.
5. 인증에 성공하면 새 비밀번호와 확인 값을 입력한다.
6. 두 값이 일치하면 비밀번호를 변경하고 로그인 화면으로 이동한다.

**예외 및 안내**

- 인증번호가 올바르지 않거나 만료되면 재입력 또는 재전송 안내를 표시한다.
- 비밀번호와 비밀번호 확인 값이 다르면 변경 요청을 진행하지 않는다.

## 1.6 가족 공유 코드 연결

### 가족 공유 코드가 있는 경우

1. 사용자가 가족 공유 코드가 있음을 선택한다.
2. 가족에게 전달받은 코드를 입력한다.
3. 코드가 유효하면 기존 가족에 참여한다.
4. 보조 담당자는 시니어와의 관계를 선택하거나 직접 입력한다.
5. 시니어 사용자는 가족 참여가 완료되면 시니어 홈 화면으로 이동한다.

### 가족 공유 코드가 없는 자녀 사용자의 경우

1. 자녀 사용자가 가족 공유 코드가 없음을 선택한다.
2. 새로운 가족 공유 코드를 생성한다.
3. 생성된 코드를 복사하거나 카카오톡·문자로 가족에게 전달한다.
4. 시니어의 이름, 관계, 생년월일, 전화번호를 입력한다.
5. 주소 검색을 이용해 시니어의 집 주소와 위치를 등록한다.
6. 정보 등록을 완료한 사용자는 주 담당자가 된다.
7. 자녀 메인 화면으로 이동한다.

**예외 및 안내**

- 유효하지 않은 가족 코드를 입력하면 가족에 참여하지 않고 재입력을 안내한다.
- 시니어 사용자는 새 가족을 생성하지 않고 자녀에게 전달받은 가족 코드로 참여한다.

# 2. 자녀(보호자) 사용자 시나리오

## 2.1 자녀 메인 화면

1. 사용자가 자녀 메인 화면에 진입한다.
2. 하단 메뉴에서 화면, 건강, 알림, 가족, 설정 탭을 선택한다.
3. 각 탭 진입 시 최신 정보를 조회한다.
4. 사용자가 화면을 아래로 당기면 해당 탭의 정보를 새로고침한다.

**예외 및 안내**

- 데이터 조회에 실패하면 기존 화면을 유지하고 오류 또는 재시도 안내를 표시한다.

## 2.2 시니어 기기 연결

1. 화면 탭에서 시니어 기기의 연결 상태를 확인한다.
2. 연결된 기기의 이름, 온라인 상태, 배터리 잔량과 최근 연결 시간을 확인한다.
3. 기기 항목을 선택해 상세 연결 상태를 확인한다.
4. 필요한 경우 시니어 기기의 연결을 해제한다.
5. 연결된 기기가 없으면 시니어ON 설치 및 가족 코드 연결 방법을 확인한다.
6. 설치 안내를 카카오톡으로 공유할 수 있다.

**예외 및 안내**

- 시니어 기기가 오프라인이면 일부 설정이 즉시 반영되지 않을 수 있음을 안내한다.

## 2.3 시니어 정보 관리

1. 화면 탭 또는 설정의 연결된 기기에서 시니어 정보를 선택한다.
2. 시니어의 이름, 관계, 생년월일, 전화번호와 주소를 확인한다.
3. 변경할 정보를 수정한다.
4. 주소 변경 시 주소 검색 결과에서 새 주소를 선택한다.
5. 저장하면 변경된 시니어 정보가 반영된다.

## 2.4 시니어 홈 화면 미리보기

1. 현재 시니어 기기에 적용된 홈 화면을 확인한다.
2. 시계, 오늘 일정, 글씨 크기, 음악 카드와 버튼 배치를 확인한다.
3. 크게 보기를 선택해 전체 화면으로 확인할 수 있다.
4. 시니어 기기가 오프라인이면 변경 사항의 반영이 지연될 수 있음을 안내한다.

## 2.5 글씨 크기 편집

1. 주 담당자가 글씨 크기 편집을 선택한다.
2. 크게, 보통, 작게 중 하나를 선택한다.
3. 미리보기에서 변경 결과를 확인한다.
4. 저장하면 시니어 홈 화면에 적용된다.

## 2.6 홈 화면 버튼 편집

1. 주 담당자가 버튼 편집을 선택한다.
2. 현재 등록된 홈 화면 버튼을 확인한다.
3. 버튼 이름을 변경하거나 불필요한 버튼을 삭제한다.
4. 새 버튼 추가를 선택한다.
5. 기본 기능 또는 시니어 기기에 설치된 앱을 선택한다.
6. 음악 앱이 필요한 경우 원하는 음악 서비스를 선택한다.
7. 버튼을 길게 눌러 표시 순서를 변경한다.
8. 저장하면 변경된 버튼 구성이 시니어 홈 화면에 적용된다.

**예외 및 안내**

- 시니어 기기에 앱이 설치되어 있지 않으면 해당 앱의 스토어 화면으로 이동할 수 있다.
- 긴급알림 버튼은 안전을 위해 지정된 위치에 유지된다.

## 2.7 복약 관리

1. 건강 탭에서 선택한 날짜의 복약 현황과 등록된 약 목록을 확인한다.
2. 날짜 이동 또는 달력을 이용해 다른 날짜를 선택한다.
3. 복약 추가를 선택한다.
4. 약 이름, 선택 성분명과 복용 시간을 입력한다.
5. 복용 시작일과 매일 또는 매주 반복 주기를 설정한다.
6. 계속 복용, 복용 기간 또는 종료 날짜를 설정한다.
7. 약 추가를 눌러 등록한다.
8. 등록된 약을 선택해 상세 정보를 확인하고 수정하거나 삭제한다.
9. 시니어가 복약을 확인하면 해당 날짜의 복용 상태가 갱신된다.

**예외 및 안내**

- 같은 복용 시간이 중복되면 등록하지 않고 중복 시간 안내를 표시한다.
- 종료 날짜가 시작 날짜보다 빠르면 등록하지 않고 날짜 확인 안내를 표시한다.
- 등록·수정·삭제 요청 중에는 중복 요청을 방지하고 진행 상태를 표시한다.

## 2.8 병원 일정 관리

1. 건강 탭에서 병원을 선택한다.
2. 다가오는 진료와 선택한 월의 병원 일정을 확인한다.
3. 날짜를 선택해 해당 날짜의 진료 목록을 확인한다.
4. 진료 추가를 선택한다.
5. 병원 이름, 진료 과목, 날짜와 시간을 입력한다.
6. 알림을 받을 시점을 선택한다.
7. 저장하면 일정에 반영된다.
8. 등록된 진료를 선택해 수정하거나 삭제한다.

**예외 및 안내**

- 동일한 날짜와 시간에 여러 일정이 있더라도 각각의 일정으로 표시한다.
- 저장·수정·삭제 요청 중에는 중복 요청을 방지하고 진행 상태를 표시한다.

## 2.9 안전 알림 확인 및 설정

1. 알림 탭에 진입한다.
2. 긴급알림, 무활동 감지, 위험 링크 감지, 외출·귀가 알림을 확인한다.
3. 최근 24시간 이내 수신한 알림을 메인 화면에서 확인한다.
4. 알림 종류를 선택해 전체 알림 내역을 확인한다.
5. 특정 알림을 선택해 위치, 배터리, 감지 시간 등 상세 내용을 확인한다.
6. 상세 화면에서 시니어에게 전화하거나 위치 길찾기를 실행한다.
7. 필요한 알림 기능을 켜거나 끈다.
8. 무활동 감지 기준 시간을 설정한다.

**예외 및 안내**

- 긴급알림은 항상 제공되는 안전 기능으로 별도 토글을 제공하지 않는다.
- 외출·귀가 알림은 시니어의 집 주소가 등록되어 있어야 활성화할 수 있다.
- 시니어 기기가 오프라인이면 설정 변경을 제한하고 인터넷 연결 안내를 표시한다.

## 2.10 가족 구성원 관리

1. 가족 탭에서 가족 구성원과 담당 역할을 확인한다.
2. 가족 추가를 선택해 가족 공유 코드를 확인한다.
3. 코드를 복사하거나 카카오톡·문자로 공유한다.
4. 주 담당자는 다른 보호자에게 주 담당자 역할을 변경할 수 있다.
5. 더 이상 함께 관리하지 않는 가족 구성원을 삭제할 수 있다.

## 2.11 가족 사진 공유

1. 가족 탭에서 사진 올리기를 선택한다.
2. 갤러리에서 사진을 선택하거나 카메라로 촬영한다.
3. 함께 전달할 메시지를 작성한다.
4. 공유하기를 누른다.
5. 공유한 사진은 시니어 기기의 가족이 보낸 사진에 표시된다.
6. 가족 구성원별 앨범과 전체 사진 목록을 확인한다.
7. 사진 상세 화면에서 사진과 메시지, 전송 시간을 확인한다.

**예외 및 안내**

- 사진 업로드에 실패하면 완료 화면으로 이동하지 않고 재시도할 수 있도록 안내한다.

## 2.12 계정 및 설정 관리

1. 설정 탭에서 프로필을 확인한다.
2. 프로필 사진을 앨범 또는 카메라로 변경한다.
3. 내 계정에서 이름과 비밀번호를 변경한다.
4. 연결된 기기에서 시니어 기기 및 시니어 정보를 관리한다.
5. 자주 묻는 질문과 앱 설치 가이드를 확인한다.
6. 1:1 문의 제목과 내용을 작성하고 필요한 사진을 첨부한다.
7. 문의 내역에서 답변 상태와 내용을 확인한다.
8. 로그아웃하거나 회원 탈퇴를 진행한다.

# 3. 시니어 사용자 시나리오

## 3.1 시니어 모드 초기 설정

1. 시니어 사용자가 가족 공유 코드 연결을 완료한다.
2. 알림 권한을 허용한다.
3. 외출·귀가 및 긴급알림 위치 전송을 위해 위치 권한을 허용한다.
4. 안내에 따라 백그라운드 위치 권한을 항상 허용으로 설정한다.
5. 시니어ON을 기본 홈 앱으로 선택한다.
6. 위험 링크 검사를 사용하려면 시니어ON이 외부 웹 링크를 처리할 수 있도록 설정한다.
7. 설정이 완료되면 시니어 홈 화면을 표시한다.

**예외 및 안내**

- 필수 권한을 거부하면 해당 기능을 사용할 수 없는 이유와 권한 설정 방법을 안내한다.
- 서버 연결에 실패해도 전화, 메시지, 카메라처럼 기기에서 실행 가능한 기본 홈 기능은 계속 제공한다.

## 3.2 시니어 홈 화면 이용

1. 홈 화면에서 날짜, 시간과 날씨를 확인한다.
2. 오늘 일정이 있으면 일정 요약을 확인한다.
3. 큰 버튼을 눌러 전화, 메시지, 카메라, 사진 등의 기능을 실행한다.
4. 자녀가 추가한 앱 버튼을 누르면 해당 앱을 실행한다.
5. 앱이 설치되어 있지 않으면 스토어의 앱 상세 화면으로 이동한다.
6. 화면을 아래로 당겨 최신 일정과 버튼 정보를 불러온다.

## 3.3 오늘 일정 확인

1. 시니어가 오늘 일정 카드를 선택한다.
2. 오늘 등록된 일정을 시간순으로 확인한다.
3. 일정이 없으면 오늘 일정이 없다는 안내를 확인한다.
4. 돌아가기를 눌러 홈 화면으로 이동한다.

## 3.4 말벗 이용

1. 시니어가 말벗 버튼을 선택한다.
2. 원형 버튼을 눌러 대화를 시작한다.
3. 화면 안내에 따라 이야기한다.
4. 시스템 응답이 끝나면 대화를 계속할 수 있다.

> 말벗 기능은 프론트 API 연동을 완료하지 못해 현재 화면 흐름과 데모 데이터만 제공한다.

## 3.5 복약 확인

1. 복용 시간이 되면 시스템 알림과 복약 안내 모달을 표시한다.
2. 시니어가 복약 확인하기를 선택한다.
3. 오늘 복용할 약의 이름과 복용 시간을 확인한다.
4. 약을 먹은 뒤 복용하기를 누른다.
5. 복약 완료 정보가 자녀에게 전달된다.
6. 해당 약은 먹었어요 상태로 변경된다.

**예외 및 안내**

- 설정된 복용 시간에서 허용 범위를 벗어나면 복용 시간이 아니라는 안내를 표시한다.
- 이미 복용 처리된 약은 다시 요청하지 못하도록 처리한다.

## 3.6 가족 사진 확인

1. 시니어가 사진 버튼을 선택한다.
2. 가족이 보낸 사진 또는 내 갤러리를 선택한다.
3. 가족 구성원별 앨범에서 공유된 사진을 확인한다.
4. 사진과 함께 전달된 메시지와 시간을 확인한다.
5. 사진을 실제로 열면 확인한 사진으로 처리된다.

## 3.7 긴급알림 전송

1. 시니어가 긴급알림 버튼을 선택한다.
2. 5초 카운트다운이 시작된다.
3. 바로 보내려면 다시 보낼게요를 누른다.
4. 취소하지 않으면 5초 뒤 자동으로 전송한다.
5. 현재 위치와 배터리 정보를 자녀에게 전달한다.
6. 전송이 완료되면 완료 화면을 표시한다.

**예외 및 안내**

- 위치를 확인하지 못하면 위치 확인 불가를 안내하고, 가능한 정보로 긴급알림 전송을 시도한다.
- 네트워크 전송에 실패하면 재전송할 수 있도록 안내한다.

## 3.8 위험 링크 보호

1. 시니어가 시니어ON이 처리하도록 연결된 외부 웹 링크를 누른다.
2. 시니어ON이 링크의 안전 여부를 서버에 요청한다.
3. 검사 중에는 링크 확인 화면을 표시한다.
4. 안전한 링크이면 외부 브라우저에서 해당 주소를 연다.
5. 위험한 링크이면 브라우저를 열지 않고 경고 화면을 표시한다.
6. 돌아가기를 눌러 이전 화면으로 이동한다.

**제한 사항**

- 사용자가 크롬 등 외부 브라우저를 직접 열어 검색하거나 주소를 입력하는 동작은 시니어ON이 감지하지 않는다.
- 네트워크 문제로 안전 여부를 확인하지 못하면 임의로 링크를 열지 않고 오류를 안내한다.

## 3.9 외출·귀가 및 무활동 감지

1. 등록된 집 위치와 시니어 기기의 현재 위치를 기준으로 외출 여부를 확인한다.
2. 시니어가 집을 벗어나면 자녀에게 외출 알림을 전달한다.
3. 외출 중에는 시니어의 최근 위치를 주기적으로 갱신한다.
4. 시니어가 집 근처로 돌아오면 귀가 여부를 재확인한 뒤 귀가 알림을 전달한다.
5. 자녀가 설정한 시간 동안 화면 잠금 해제나 런처 조작이 없으면 무활동 알림을 전달한다.
6. 자녀는 알림 상세에서 이벤트 당시 위치, 배터리와 감지 시간을 확인한다.

**예외 및 안내**

- 위치 권한 또는 위치 서비스가 꺼져 있으면 외출·귀가 감지가 제한됨을 안내한다.
- 기기가 오프라인이면 위치와 무활동 알림 전송이 지연될 수 있다.

# 4. 공통 오류 및 복구 원칙

1. 네트워크 오류가 발생하면 앱이 종료되지 않고 사용자에게 오류 원인과 재시도 방법을 안내한다.
2. 저장·수정·삭제 중에는 진행 상태를 표시하고 같은 요청이 여러 번 전송되지 않도록 한다.
3. 조회에 실패했을 때 기존에 확인한 데이터가 있으면 화면에서 즉시 제거하지 않는다.
4. 필수 입력값이 없거나 형식이 올바르지 않으면 해당 항목을 안내하고 요청을 전송하지 않는다.
5. 권한이 필요한 기능은 권한이 필요한 이유와 시스템 설정 이동 방법을 함께 안내한다.
6. 인증 세션을 갱신할 수 없으면 자녀 모드는 로그인 화면으로 이동하고, 시니어 모드는 기본 홈 기능을 유지하면서 서버 기능을 제한한다.
