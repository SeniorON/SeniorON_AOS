# Mock Test Data

이 문서는 로컬 UI 흐름 테스트용 목데이터입니다.

## 관리 기준

- 여러 기능이 함께 사용하는 사용자·가족·시니어·기기 정보는
  `data/repository/mock/fixtures`를 단일 기준으로 사용합니다.
- 로그인, 가족 탭, 설정 탭에서 같은 사용자 아이디는 같은 이름과 이메일을 표시합니다.
- 시니어의 이름·생년월일·전화번호·주소는 공통 정보이고, 보호자 관계는
  `userId + seniorId` 조합별로 저장합니다.
- 알림 유무나 기기 연결 상태처럼 기능별로 달라지는 시나리오는 각
  `MockRepository`에서 공통 fixture를 조합해 만듭니다.
- Compose Preview만을 위한 임시 상태는 UI 파일에 둘 수 있지만, 공통 사용자 이름이나
  시니어 정보는 fixture를 참조합니다.

## 가족사진 시나리오

- 초기 사진은 김민지 10개, 김지은 3개로 총 13개입니다.
- 자녀 가족 탭 메인에는 최근 사진 4개만 표시하고, `사진 더보기`에는 13개 전체를 표시합니다.
- 부모님 가족사진 화면은 같은 13개를 올린 가족 구성원별로 묶어서 표시합니다.
- 자녀가 사진을 올리거나 삭제하면 공통 메모리 Store를 통해 부모님용 Repository에도 반영됩니다.
- 메모리 Store이므로 앱 프로세스를 완전히 종료하면 사진 변경 내용은 초기 13개로 돌아갑니다.
